# KrishiSahay location data

`src/data/states-and-districts.json` is the UI's normalized English state/UT → district list. The current snapshot contains 35 state/UT labels and 722 district labels, including the Phase 3 demo districts Nadia, Ludhiana, and Nagpur.

Reference pages for manual refresh and discrepancy checks:

- India State/UT & Districts: https://www.india.gov.in/explore-india/facts-of-india/states-ut-districts
- India district directory: https://www.india.gov.in/directory/web-directory/districts

The application does not present this list as live evidence. Search results, schemes, alerts, prices, Maps listings, Trends, and videos are independently retrieved and cited at run time. Administrative changes should be reviewed against the reference pages before a production release.
